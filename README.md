# Deepavali Verse

A vibrant, interactive Deepavali world built with React, TypeScript, CSS, SVG and Canvas.

## Experiences
- **Grand Courtyard** — illustrated palace atmosphere, animated lights and discoverable destinations.
- **Rangoli Atelier** — colourable SVG rangoli with undo and PNG export.
- **Fireworks Terrace** — Canvas particle fireworks; click or tap to launch bursts.
- **Sweet Bazaar** — Laddu Catcher mini-game with score and local best score.
- **Lantern Ghat** — write and release a wish; wishes are saved locally in the browser.
- **Greeting Pavilion** — personalised card, PNG download and WhatsApp sharing.
- **Diya lighting** — light individual lamps; progress persists locally.

## Stack
React 18, TypeScript, Vite, Framer Motion, Zustand, Lucide and html-to-image.

## Development
\`\`\`bash
npm install
npm run dev
npm run typecheck
npm run build
\`\`\`

No backend or terminal/debug interface is included. User progress is stored in localStorage.
