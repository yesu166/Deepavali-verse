# Deepavali Verse

An immersive, interactive Deepavali world built with React, TypeScript, CSS, SVG and Canvas.

## Experiences
- Grand Courtyard with animated illustrated palace, rangoli, decorative lamps and discoverable destinations.
- Diya lighting with locally persisted progress.
- Rangoli Atelier with interactive SVG petals, colour palettes, undo/reset and PNG export.
- Fireworks Terrace with a Canvas 2D particle system and click/tap launches.
- Sweet Bazaar with a timed Laddu Catcher game and locally persisted best score.
- Lantern Ghat with wish writing, release animation and locally stored wishes.
- Greeting Pavilion with personalised cards, PNG download and WhatsApp sharing.

## Stack
React 18 · TypeScript · Vite · Framer Motion · Zustand · Lucide · html-to-image

## Local development
\`\`\`bash
npm install
npm run dev
npm run typecheck
npm run build
\`\`\`

No backend or terminal/debug interface is included. Experience progress is stored in the browser.
